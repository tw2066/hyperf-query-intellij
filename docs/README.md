# Hyperf Query 使用文档

**Hyperf Query** 是一款 JetBrains IDE 插件(PhpStorm / 带 PHP 与 Database 插件的 IntelliJ IDEA),为 **Hyperf** 的查询构建器、模型、Schema 构建器提供数据库级别的代码补全、未知元素检查、Ctrl+Click 跳转与悬停文档。

> **前置条件**:插件的所有表/列信息都来自 IDE 的数据源(Database 工具窗口),**使用前必须先配置并刷新数据源**,否则不会有任何补全。
